从 Windows 底层开发到网络安全：我的学习路线

发表于2026-07-30|更新于2026-07-30|学习笔记
|浏览量:

起点

我最初接触计算机时，更多关注的是软件开发和系统底层原理。

相比于单纯调用高级接口完成应用开发，我更喜欢了解程序运行背后的机制，例如：

  • 操作系统如何管理进程和线程
  • 程序如何加载和执行
  • 用户态与内核态之间如何交互
  • 硬件资源如何被系统抽象和管理

随着学习深入，我逐渐发现，系统底层知识与网络安全之间存在非常紧密的联系。

安全问题很多时候并不是单独存在于某个漏洞或工具中，而是建立在对操作系统、程序运行机制以及计算机体系结构的理解之上。

因此，我开始尝试向网络安全方向扩展。

当前学习方向

目前我的学习重点主要集中在 Windows 平台安全相关方向。

用户态安全研究

用户态是大多数程序运行的环境，也是理解安全机制的重要入口。

目前主要学习：

  • Windows API 调用机制
  • 进程与线程管理
  • PE 文件结构
  • 调试与程序分析
  • 系统信息采集

这些内容帮助理解一个程序从启动到运行过程中发生了什么。

Windows 内核与驱动开发

Windows 内核提供了更加底层的系统控制能力，也是系统安全研究的重要方向。

目前正在学习：

  • Windows 驱动开发模型
  • WDM 基础结构
  • IRP 请求处理机制
  • 内核对象管理
  • 用户态与内核态通信

通过驱动开发，可以进一步理解操作系统内部工作方式。

安全工具开发

在学习过程中，我也尝试开发一些辅助分析工具。

目前正在开发的项目是 SnowSword，一个面向 Windows 平台的系统分析工具。

项目主要用于：

  • 学习 Windows 系统内部结构
  • 实践系统信息采集
  • 验证安全分析相关技术

通过实际开发工具，可以将理论知识转化为更加具体的实践经验。

后续会单独记录项目开发过程中的设计思路和遇到的问题。

后续学习计划

未来希望继续完善自己的知识体系：

Windows方向

  • 深入学习 Windows Internals
  • 研究系统安全机制
  • 学习恶意代码分析方法
  • 提升逆向分析能力

网络安全基础

  • 网络协议
  • 常见漏洞原理
  • Web安全基础
  • 密码学基础

实践方向

  • 参与 CTF 或安全实验
  • 阅读优秀安全项目源码
  • 通过实际项目提升工程能力

当前不足

目前我的学习方向更加偏向 Windows 系统和底层开发，在网络方向还有很多需要补充的地方。

例如：

  • 网络协议知识还需要系统学习
  • Linux 安全生态接触较少
  • 安全分析经验仍需要通过更多实践积累

因此，后续会逐步完善自己的知识结构，而不是局限于某一个方向。

总结

网络安全是一门综合性很强的领域。

工具、框架和环境会不断变化，但对计算机基础原理的理解始终具有价值。

希望通过博客记录自己的学习过程，将零散的知识整理下来，也方便未来回顾自己的成长路线。

这也是开始记录网络安全学习的第一步。
